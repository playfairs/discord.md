# Server Tags and Gradient Role Colors

# What are these?

Server Tags and Gradient Role Colors are an experiment Discord is testing which has yet to be released for all servers; there are few servers with this feature, and there is no current way to unlock the ability to add them to your server at this moment

## Server Tags:

Server Tags: Something that Discord removed a while back which used to be called "Guild Tags" which was part of the "Guilds" experiment, was then removed, and then reintroduced into Servers as Server Tags, but without the 200 member limit.

### Can I make my own Server Tag?

No, this is currently only an experiment and no more than around 30 servers have these experiments, it is unsure when Discord may make these changes public for all servers, or if they will remove them like they did with Guilds.

### How do I obtain a server tag?

To obtain a Server Tag is very simple, all you need to do is join a Server which has a Server Tag, then you can go to your profile customization, and at the bottom select the Server Tag you want to represent, you can have as many as you want, but can only have one Active Tag.

### My Server Tag changed / disappeared, why?

Your Server Tag can change for various of reasons, the main reason is normally just that the owner of the server which has the Server Tag simply changed, it this does not have a limit to how much it can be done in total, so it can be changed as much as the owner pleases, a reason it could have disappeared is most likely just that you were removed from the server, or you left, when you leave or get kicked from a server with a Server Tag, you lose that Server Tag, they only remain so as long as you are in that Server.

### Others have a different icon than me, but the same tag, why?

Sometimes when the owner of a Server Tag changes it's icon, the icon doesn't always change for everyone immediately, this is due to how Discord caches the Icons which a users currently set Server Tag works, normally you can either change it manually by removing them reapplying the tag, or hard-reload discord / restart your client, this will clear the cache and your tag SHOULD change, if it does not, then you may need to wait.

"And mostly so the servers don't blow up when it has to change a profile field for 300k people at once. Its still being worked on how exactly it should work." - Tech

### How can I change my Server Tag Icon?

You can't, only the owner of the server can change the icon, if you see others with a different icon, then it's a visual bug.

### People have a different Server Tag name, even though were in the same Server, **why**?

Like the Server Tag icon, changes made to the Server Tag don't apply to the users repping that tag instantly, in fact, for the name, they don't change unless you specifically unapply and reapply the tag, so you can technically choose to either keep the tag the way it is for you, or you can choose to reapply the tag with the change, this obviously is not why it is like that though.
