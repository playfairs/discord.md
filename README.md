# discord.md

## What is the point of this Repository?

Information. People love information, people like in depth details about certain things they are unsure about, it is better to fully inform someone about a feature or experiment so they fully understand how it works and the point of it, sure, you can read documentation or look at YouTube videos for this stuff, but I chose to do this for the sake of helping people, and also because I myself like to have a place to post what I learn about Discord. I also made this Repository to save some people time trying to explain to someone how something works, you're welcome tech.

## How do I know if the Information on this Repository is true?

Research. Before I write, I do research, I want to be sure that the information I am putting out is correct and up to date with how Discord currently stands, it is better to be 100% certain about something, than to just guess, if you are unsure if something is correct, you can look it up with other sources, you are not obligated to believe everything on this Repository.

## What Information will this Repository cover?

This Repository will cover things such as Experimental Features which have not been fully if at all released to Discord Stable, Base Features, Server Guides, Discord Bots, and more, it may also include things which are related to discord.py, the Python Library for creating Discord Bots, Created and Maintained by [Rapptz](https://github.com/Rapptz), for more Official information on discord.py, you can check out [discordpy.readthedocs.io](https://discordpy.readthedocs.io/en/stable/).
