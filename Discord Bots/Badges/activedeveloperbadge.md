# Active Developer Badge

## What is the Active Developer Badge?

The Active Developer Badge is a badge that Discord gives to Developers who's Applications (Bots) have ran Application Commands frequently, it is mostly easy to obtain, but to maintain it, you need to ensure that your bot is active and running commands regularly. The Badge will go away otherwise.

## How do I get the Active Developer Badge?

To get the Active Developer Badge, you first need to create an application, you can go to the [Discord Developer Portal](https://discord.com/developers/applications) and create a new application. Once you have created your application, Reset the token to get started, for more information on how to create a Discord Bot, check out [Discord.py](https://discordpy.readthedocs.io/en/stable/) or [Discord.js](https://discord.js.org/#/docs/main/stable/general/welcome), or look into other Discord Libraries for your preferred language.

## I created the Bot and it's running commands, but I don't have the Active Developer Badge, why?

Unlike most badged, the Active Developer Badge is an optional badge which does not appear on it's own, assuming you are eligible for it, go to the [Active Developer Badge](https://discord.com/developers/active-developer) to claim it, if you are still not able to claim it, there could be a few reasons.

In order to be eligible for the Active Developer Badge, your bot must meet these requirements:

- Your bot must be active and online.
- Your bot must have Application Commands. (Slash Commands).
- Your bot must run 1 Application Command every 30 days at least.
- You must own the bot.

If you are still unable to claim the badge, you may need to wait for Discord to process the application as an Active Application.

## Someone has the Badge but theirs is blue, why?

If you see someone with the Active Developer Badge but blue, this isn't the Active Developer Badge, It's the Early Verified Bot Developer badge, awarded to developers who verified their bots early before Discord transitioned to the current badge system.
